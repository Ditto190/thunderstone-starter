# Conventions
- Follow `AGENTS.md`: do not auto-approve shell/MCP, push/deploy, delete remote data, or message other people.
- Never include secrets, personal data, or absolute local paths in commits; use relative paths.
- Do not push to main or alter rulesets; work on a branch and open a PR.
- Reports state outcome, changed files, validation, blockers, next action; avoid raw log dumps.
- Keep workspace briefs/handoffs as project artifacts; agent receipts are versioned evidence and deterministic tests enforce promotion gates.
